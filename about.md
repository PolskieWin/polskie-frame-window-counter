# Polskie Frame Window Counter

Custom Frame Window Counter mod created by **Polskie**, faithfully recreating the **NaN GD** & **Razy's Frame Windows** layout with RobTop's iconic Pusab font.

## 🎮 Key Features

- 🔤 **Authentic Pusab Font (`bigFont.fnt`)** — HUD and GUI styled after native Geometry Dash menus.
- 🎯 **1:1 NaN GD Frame Window Buckets:**
  - `10+:` (Violet `#BA5DF9`)
  - `9-10:` (Purple `#8A5FF9`)
  - `7-8:` (Light Blue / Cyan `#59C9D7`)
  - `5-6:` (Lime Green `#77DF91`)
  - `3-4:` (Pastel Yellow `#D0D53B`)
  - `1-2:` (Warm Amber / Orange `#E8A020`)
  - `0-1:` (Frame Perfect Pink/Red `#EF4F50` — **CBF Frame Perfect!**)
- ⚡ **Milliseconds (MS) & Effective Refresh Rate (Hz):**
  - Accurate average window duration (e.g. `21.13MS`)
  - Effective Hz calculated in real time (e.g. `240Hz`)
- 🏆 **Dynamic CBF (Click Before Frame) Status:**
  - Flashes `CBF: X (Frame Perfect!)` in bright yellow upon hitting a 0-1f window!
  - Displays sleek `CBF: X` during standard gameplay.
- 🔔 **Frame Perfect Sounds (NaN GD Style):**
  - Crystal clear success chime (ding / coin / chime) on Frame Perfect clicks!
- 💍 **Ring / Orb Frame Perfect Tracking:**
  - Detects and counts Frame Perfect hits on jump rings / orbs (`RINGS FP: X/Y`).
- 🕹️ **Full Gamemode Support:**
  - Physics window analysis for Cube, Ship, Ball, UFO, Wave, Robot, Spider, Swing.
- 📁 **Universal Bot Macro Import:**
  - **Native file picker** support (`file::pick`) to select macros anywhere on your device!
  - **Eclipse Menu** (`.gdr2`, `.gdr` — "esplice")
  - **MegaHack Replay** (`.mhr` binary & `.mhr.json`)
  - **TASBot / Generic JSON** (`.json`)
  - **Plain Text / CSV** (`.txt`)
- ⚙️ **In-Game Settings GUI:**
  - Click the `[FWC]` button in the Pause Menu to open the full configuration panel!
- 📱 **Cross-Platform Compatibility:**
  - Android (32-bit & 64-bit) and Windows (64-bit)
  - Geometry Dash 2.2071, 2.2074, 2.2081, 2.2091
